# My Paint 🎨

A simple paint application built with **Python** and **PySide6** (Qt for Python).

**This is my very first Python project.** I started this knowing nothing about coding, and this repository is the journey of me learning Python from zero — one line at a time.

Rather than copying a tutorial, I'm building every feature by hand, step by step: understanding each concept before writing it, breaking things, reading error messages, and fixing them. The commit history *is* the learning curve.

## Features

### Done ✅
- Application window

### In progress 🚧
- Freehand drawing with the mouse

### Planned 🗺️
- Straight lines (with horizontal/vertical snapping)
- Rectangles/boxes
- Color picker
- Eraser
- Undo and redo

## Requirements

- Python 3.9 or newer
- PySide6

## What I'm learning along the way

- How GUI programs use an **event loop** instead of running top to bottom
- Handling **mouse events** (press, move, release)
- Keeping an image in memory and mirroring it to the screen with `paintEvent`
- Classes and object-oriented programming in Python
- Using **stacks** to implement undo/redo
